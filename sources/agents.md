# Agents: starter notes

An AI agent is a system that pursues a goal by choosing actions and observing their results. A model can be one part of an agent, alongside tools, orchestration, and deployment.

A workflow follows paths defined in advance by its author. An agent chooses at least some of its next steps based on what it observes. If every model call and tool call happens in a fixed order, the system is better described as a workflow.

A useful research answer should distinguish claims supported by the available sources from claims that are not supported. Source names and locations should accompany claims so a reader can verify them.
